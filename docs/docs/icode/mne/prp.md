# PRP Instruction

## Synopsis

```
PRP <routineLabel> <routineLevel> <isLibraryRoutine>
```

## Description

The **PRP** instruction pushes a routine pointer to the stack.

## RoutineLabel Operand

This is the label of the routine to reference.

## RoutineLevel Operand

The scope level of the routine.

## IsLibraryRoutine Operand

This is non-zero if the routine is in a library.
