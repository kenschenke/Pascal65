0.37-beta Nov 20 2026
    NEW: The IDE keeps a build's errors and warnings instead of printing
         them, and goes straight back to the editor after a build. A
         line above the key help shows the result of the last build
    NEW: F11 and F9 step through the errors and warnings, opening the
         file and highlighting the line in the theme's error or warning
         color
    FIX: F11 deleted to the end of the line, and F12 and F13 changed the
         screen size
    FIX: Fix the parser when recovering from an error
    FIX: Unary minus of a variable, expression or function call was ignored
    FIX: A negative real number, such as -2.5, was positive
    FIX: Subrange limits of different integer types, such as 1..1000 or
         a constant and a number, were refused
    FIX: A subrange's variables are the integer type that holds both
         limits, such as Integer for -1000..1000
    FIX: Comparing a variable of a subrange type was refused
    FIX: Negative and character values of a subrange variable were wrong
    FIX: A variable of an enumeration subrange type, such as Red..Green,
         corrupted the variables declared after it
    FIX: A routine declared Forward that never got a body wasn't reported
    FIX: A record field of a type that isn't declared wasn't reported,
         and could corrupt the compiler's memory
    FIX: An array index type that isn't declared wasn't reported
    FIX: An array index of a type such as Char, Boolean or Byte, or an
         enumeration written in place, gave the array one element. It's
         now an error. Use a subrange, such as Array['a'..'z'], or a
         declared enumeration or subrange.
    FIX: An array element type that isn't declared wasn't reported
    FIX: A field that isn't declared, or of a record that isn't, was
         reported two or three times
    FIX: An enumeration value with the name of another identifier, such
         as a value of another enumeration, wasn't reported
    NEW: Sound library: the 12 voices of the MEGA65's four SIDs, notes
         that play for a number of frames without waiting, sweeps,
         vibrato and pulse width effects, sequences that play a tune
         under the program, and a callback when a voice finishes
    NEW: sfxdemo.pas, tunedemo.pas and stereodemo.pas examples of the
         Sound library on the compiler disk
    NEW: A library object file can carry a relocation table (version 2),
         so its code can hold any bytes
    FIX: A Const block in a library's interface broke programs that used
         the library
    FIX: Arithmetic on a signed and an unsigned constant, such as 1234
         and -500, could give an unsigned result
    FIX: Arithmetic with a number in it, such as 4 * 12, warned of a loss
         of precision when assigned to a Word, or of mixed signs when
         compared with one
    FIX: A large static program could crash when it ended
    FIX: The raster and sprite collision callbacks left a byte on the CPU
         stack each call and could upset the code they interrupted
    FIX: A procedure called without parentheses just before End, Else or
         Until, such as If a Then DoIt Else ..., was an error
    FIX: Reduced the compiler's memory use, so larger programs compile
    FIX: Compiled programs are smaller: a routine call, reading a variable
         and an assignment take fewer bytes. The runtime files are now
         core3, runtime3 and so on
    FIX: A String returned by a function, such as UpCase or Trim, was
         never freed, so a program that called one in a loop ran out of
         memory
    FIX: A program stopped by a runtime error, such as running out of
         memory, crashed or hung instead of returning to BASIC, and its
         libraries didn't clean up (sound kept playing)
    FIX: A program could corrupt its memory instead of reporting that it
         ran out of memory
    FIX: A raster, sprite collision or sound callback that multiplied or
         divided could change the result of the program's own
         multiplication or division
    FIX: An array of records, such as Array[1..3] Of Point, or a record
         holding records, set up its records at the wrong places in
         memory, the last one past the end of the variable
    NEW: Hangman, a game using the Screen and Sound libraries, on its
         own disk (hangman.d81) that boots into the game. Its source is
         examples/hangman.pas
