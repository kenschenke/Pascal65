# The editor's shipped themes. mkthemes.py turns this into themes.def,
# which the root Makefile writes to the disk as themes.dat and themes.def.
#
# A color line is:
#   <color> <index> <r> <g> <b>   palette index 0-31, then RGB 0-15
#   <color> <index>               the MEGA65 default RGB for that index
#   <color> <other color>         a copy of the theme's other color
# The colors are number, keyword, string, comment, operator, identifier,
# cursor, ui, background, error and warning. Every theme names each once,
# in any order. Format 0 (the old file) ignores error and warning. The
# error and warning colors are placeholders for now: copies of the UI
# color, which can't clash with the theme's palette.
#
# A color's RGB is written into its palette slot, so two colors on the
# same index should have the same RGB; the generator warns if they don't.
# Theme names are at most 16 characters.
