# Pre-compiled library headers

This directory holds the `.hdr` files the compiler loads in place of parsing
a library unit's `.pas` file (`system.hdr`, `screen.hdr`, and so on). The
format is described in `src/asminc/hdr.inc`.

The files are generated by the `mkhdr` app (`src/apps/mkhdr`) and checked in,
because generating them requires running on a MEGA65 or emulator.

To regenerate after changing a library's `.pas` file:

1. Build and run `mkhdr` (`make run` in `src/apps/mkhdr`).
2. Enter the unit's source file name at the prompt (for example `system.pas`).
   It writes `system.hdr` to the same disk.
3. Copy the `.hdr` file out of the mkhdr disk image into this directory
   (for example `c1541 mkhdr.d81 -read system.hdr system.hdr`).
4. Rebuild the compiler disk.

A header must match its `.lib`: both follow the order of the declarations in
the `.pas` file, so rebuild the header whenever the `.pas` changes. If a
unit has no header here, the compiler parses its `.pas` file instead.
